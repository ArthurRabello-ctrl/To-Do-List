# Gerenciador de Tarefas em Python

Aplicação de linha de comando para organizar tarefas do dia a dia, desenvolvida em Python como parte dos meus estudos de programação.

## Funcionalidades

- Adicionar novas tarefas
- Listar tarefas com indicação de status (`[ ]` pendente, `[x]` concluída)
- Marcar tarefas como concluídas
- Remover tarefas


## Exemplo de uso

```
1 - Adicionar
2 - Listar
3 - Concluir
4 - Remover
0 - Sair
Escolha: 2
1. [x] Estudar Python
2. [ ] Fazer o README
```

## Conceitos praticados

- Listas e dicionários
- Laços de repetição (`while` e `for`)
- Estruturas condicionais (`if`, `elif`, `else`)
- Entrada e saída de dados (`input` e `print`)
- Formatação de texto com f-strings
